**CLI Wordle**

- Simple wordle clone that runs entirely in terminal
- Comes with a wordlist over 3100 words long
- Checks your guess and actually colors it just like wordle does
- Doesn't require the download of any libraries, it uses built in libraries

*How To Play*

- Simply run the python script, and enter your guess
- If you input a guess that is not 5 letters long or isn't in the wordlist you will be asked again
- After you input a valid guess it compares it to the word and colors it accordingly
- Red:      Character is not used in the word
- Yellow:   Character is used but not in the current position
- Green:    Character is used and its in the correct position
- If you correctly guess the word the game ends.
- If you guessed 6 times and havent guessed the word, the game ends and reveals the word
